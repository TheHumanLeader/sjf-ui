# Table · v0.1

- 客户端稳定排序、跨页行选择、页内全选及混合态；rowKey 应提供业务稳定唯一键，避免依赖下标。
- 表头使用 aria-sort，滚动区域可聚焦；加载与空状态由 Skeleton/Empty 统一呈现。
- 分页、选择值通过 v-model:page / selected 控制；cell-[key] 插槽仅定制单元格，排序依据原始值或 compare。
- 不提供服务端分页协议或虚拟化；超大数据由业务分片，复杂表格能力留待后续版本。

## 视觉与集成

沿用 Material 3 语义色，不固化主题颜色。所有尺寸从 Ordered Size 解析，并跟随全局或 Form 的尺寸上下文；表单控件通过 Label 统一布局和状态。

动效使用统一 duration/easing；库默认遵循系统减少动态效果，文档可以显式切换完整预览。交互示例与最简 API 见文档站对应组件页。
