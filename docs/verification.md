## 修复记录

修复了模态框继承浮层根节点 pointer-events:none 导致无法点击、嵌套浮层不在 native dialog 顶层、关闭浮层焦点丢失、窄屏工具栏裁切、旧错误提示越界、图标被 flex 拉伸、多选 Tree 示例展开值不可修改、文件取消选择误清空等问题。

代码格式化暴露了当前 Vapor 编译器对多语句事件表达式的解析限制；相关事件改用显式函数，并加入全组件解析回归测试。
